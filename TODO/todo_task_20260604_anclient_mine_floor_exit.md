# Задача: кнопка `Пройти этаж` для шахты ANClient

## Цель

Добавить рядом с шахтёрскими кнопками `Ваш персонаж`/`Инвентарь` кнопку `Пройти этаж`, которая строит маршрут от текущей клетки до клетки перехода на следующий этаж и запускает существующий шахтёрский навигатор.

## Исходные данные

- Для локации `Рудник Подгорный` известны клетки перехода:
- 1 этаж: `3-3`.
- 2 этаж: `1-20`.
- 3 этаж: `1-6`.
- 4 этаж: `20-13`.
- 5 этаж: `19-12`.
- В других шахтах клетки будут другими, поэтому данные должны храниться по связке `локация/этаж`, с fallback без действия.

## Существующий контур

- `ANClient\PostFilter\MineJs.cs` добавляет кнопки в `ButtonPlace` и вызывает bridge-методы через `window.external`.
- `ANClient\Mine\AutoMineRuntime.cs` хранит текущую шахту/этаж/позицию, строит pending route через `MineMoveTo()` и отдаёт HTML клетки через `GetMineCellHtml()`.
- `ANClient\ScriptManager.cs` является COM bridge для JavaScript.

## Реализация

- `AutoMineRuntime` хранит `FloorExitTargets` по ключу `mineId:level`; для `Рудник Подгорный` используется `mineId=1`.
- `GetMineCellHtml()` подсвечивает клетку перехода зелёной рамкой и зелёным текстом координат.
- `MineMoveToFloorExit()` строит маршрут через существующий `MineMoveTo()` и включает обычный pending route/navigation flow.
- `ScriptManager` отдаёт в JS `hasMineFloorExit()` и `mineMoveToFloorExit()`.
- `MineJs` добавляет кнопку `Пройти этаж` в `ButtonPlace` рядом с `Ваш персонаж`/`Инвентарь`; для неизвестной шахты/этажа кнопка отключена.
