# Задача: стабилизация Авто-Клада при proxy и высокой фоновой нагрузке

## Контекст
- Симптом по `Logs/logcat_runtime_20260326_11.txt`:
  - маршрут строится, но периодически замирает/останавливается;
  - в цикле появляются `map_ajax ERR` во время `AutoMoving`;
  - параллельно идут `ab_nav_tick` + `ab_bg_probe` (idle-probe авто-боя), что создаёт лишнюю конкуренцию запросов через proxy.
- Требование:
  - фиксить существующие ветки, без размножения новой логики;
  - добавить понятную причину остановки Авто-Клада при усталости;
  - по умолчанию включить авто-питьё блажа по усталости.

## План
- [x] Проверить лог и подтвердить корневые триггеры.
- [x] Подавить idle server-probe авто-боя во время активного Авто-Клада (без влияния на бой).
- [x] Добавить чат-диагностику причины остановки Авто-Клада по усталости.
- [x] Сместить дефолт `DoAutoDrinkBlaz` в профильное значение `true`.
- [ ] Прогон компиляции `:app:compileDebugJavaWithJavac`.

## Реализация
- [x] `MainActivity.java`
  - добавлен guard `shouldSkipAutoTurnServerProbeForMapAutomation()`;
  - в `requestAutoTurnFromServerProbe(...)` добавлено раннее подавление `ab_bg_probe`,
    если активен `AutoMoving + DoSearchBox` и нет признаков активного боя.
- [x] `AutoModeForegroundService.java`
  - в `uiTick` добавлен ранний skip idle autoTurn/probe, когда активен Авто-Клад и бой не активен.
- [x] `MapAjax.java`
  - в ветке `map_ajax ERR` добавлен короткий backoff по `NeverTimer`, чтобы не дергать recovery в стык;
  - в ветке `too tired + DoAutoDrinkBlaz=false` добавлено системное сообщение в чат с причиной остановки Авто-Клада;
  - сообщение дедуплицируется по времени, чтобы не спамить чат.
- [x] `UserConfig.java`
  - дефолт `DoAutoDrinkBlaz` изменён на `true` для новых/неполных профилей.

## Проверка (что смотреть в следующем логе)
- [ ] Нет частых `ab_bg_probe` во время активного Авто-Клада без боя.
- [ ] Нет "пилы" из `map_ajax ERR` на каждом шаге.
- [ ] При усталости выше порога и выключенном автопитье появляется явное сообщение в чат с причиной остановки.
