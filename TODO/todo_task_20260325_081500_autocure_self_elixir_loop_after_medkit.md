# Задача: Зацикливание на "Эликсир Мгновенного Исцеления" после лечения аптечкой

## Контекст
- По логу `Logs/logcat_runtime_20260325_01.txt` после успешной отправки `doctorform` на лечение травмы (`wca=85`) происходил повторный цикл лечения в `im=6` с сообщением про "Эликсир Мгновенного Исцеления".
- Ожидаемое поведение: после лечения своей травмы локальное runtime-состояние ран должно синхронно уменьшаться, чтобы автолечение не перезапускало self-эликсир без новой травмы.

## Анализ
- В ветке `mainPhpExternalRequestedCureStep(...)` (внешний `AppVars.CureNeed`) после успешной отправки формы на лечение не уменьшался локальный счётчик ран для `self`.
- В ветке `mainPhpAutoCureStep(...)` при успешном формировании self-эликсира также не уменьшался локальный счётчик ран.
- Из-за этого `CharacterVitalsManager` продолжал видеть старую рану до следующей полной серверной синхронизации по `pinfo`, что приводило к повторным триггерам.

## План
- [x] Добавить синхронное уменьшение локального счётчика ран после успешной отправки внешнего лечения `self`.
- [x] Добавить синхронное уменьшение локального счётчика ран после успешного запуска self-эликсира.
- [x] Вынести определение индекса раны в helper (`cureTravm -> LIGHT/MEDIUM/HEAVY`), без дублирования логики.
- [x] Проверить сборку `:app:compileDebugJavaWithJavac`.
