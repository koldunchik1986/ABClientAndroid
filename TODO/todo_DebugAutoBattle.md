## Найденные проблемы

### Проблема 1: Белый экран при отключенном авто-бое
**Файл:** `MainPhp.java`, строки 587-668
**Причина:** Когда авто-бой ВЫКЛ (`AppVars.Profile.LezDoAutoboi = false`), код возвращает `AppVars.ContentMainPhp` вместо оригинального HTML боя. Это вызывает белый экран.

### Проблема 2: Белый экран при опасных условиях авто-боя
**Файл:** `MainPhp.java`, строки 612-618
**Причина:** Когда авто-бой ВКЛ, но условия опасные (DoStop, IsLowHp, IsLowMa, DoExit), код устанавливает состояние `AutoboiState.Timeout`, но затем возвращает `AppVars.ContentMainPhp` вместо оригинального HTML боя.

### Проблема 3: Информация о HP противника не отображается
**Файл:** `LezFight.java`, метод BuildFrame()
**Причина:** Frame строится с информацией о противнике, но при авто-бое сразу делается редирект (auto-submit), поэтому пользователь не видит эту информацию. В ПК версии пользователь видел фрейм перед авто--submit.
