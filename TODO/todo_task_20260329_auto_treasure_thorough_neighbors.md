# Задача: Авто-Клад — тщательная проверка соседних клеток

## Цель
- Добавить в `Авто-Клад` опцию:  
  `Тщательная проверка соседних клеток (Расходуем больше Блажа — для проверки соседних клеток)`.
- При включенной опции сначала проверять соседние клетки, если:
  - радиус от текущей клетки по Манхэттену `<= 3`;
  - путь до клетки `<= 5` шагов;
  - метка `visited` новее базовой цели не более чем на `12 часов`.
- Реализация без дублирования контура: только доработка существующего `MapAjax.findNextDestForBox(...)`.

## Реализация
- [x] Добавлен новый флаг настройки в `AutoFunctionsManager`:
  - `isAutoTreasureThoroughNeighborCheckEnabled()`
  - `setAutoTreasureThoroughNeighborCheckEnabled(boolean)`
- [x] Добавлен чекбокс в настройки `Авто-Клад` (`QuickButtonsPanel.showAutoTreasureSettingsDialog()`).
- [x] В `MapAjax` внедрён detour-слой поверх базового выбора клетки:
  - базовый выбор ("самая старая/просроченная") сохранён;
  - при включенной опции вычисляются соседние кандидаты;
  - кандидаты сортируются: `pathLen ASC`, затем `visited ASC`;
  - если кандидаты есть — идём на лучший detour, иначе используем базовую цель.
- [x] Добавлено трассировочное логирование `AUTO_SEARCH_BOX_TRACE`:
  - состояние detour-режима,
  - базовая цель,
  - список соседних кандидатов,
  - выбранная detour-цель или fallback к базовой.

## Проверки
- [ ] Опция выключена: поведение поиска полностью как раньше.
- [ ] Опция включена: при наличии подходящих соседей они выбираются перед базовой целью.
- [ ] Соседи с `visitedDelta > 12h` не попадают в detour.
- [ ] Клетки вне радиуса Манхэттен `> 3` и пути `> 5` не попадают в detour.
- [ ] Сборка проходит: `:app:compileDebugJavaWithJavac`.

## Примечание
- Алгоритм detour сделан статeless (без отдельной очереди), чтобы исключить "залипания" между циклами и не плодить дублирующие состояния.
