# Задача: приоритет "Тип противника" в Авто-Бое (C# parity)

## Контекст

Проблема: в бою применяются настройки группы `Все`, даже когда есть более специфичные группы (`Боты 10+`, `Боты 0+`, `Человек N+`, `Боссы`).

Требование: поведение 1:1 как в ПК версии C# (`ABClient/Lez/LezFight.cs`, `FormSettingsAb.cs`):
- подбор группы идёт по первому совпадению в **отсортированном** списке групп;
- допускаются несколько групп с одинаковым `Id`, но разным `MinimalLevel`;
- fallback — группа `Все 0+`.

## Диагностика

- [x] Сверена C# логика выбора группы (`LezFight.cs`): first-match по списку `AppVars.Profile.LezGroups`.
- [x] Сверена C# логика создания группы (`FormSettingsAb.cs`): вставка по `compareTo`, без автоинкремента `Id`.
- [x] Проверены Android логи `Logs/logcat_runtime_20260302_08.txt` и `Logs/logcat_runtime_20260302_09.txt`: везде выбиралась `FoeGroup Id=1`.
- [x] Найдены расхождения Android:
  - схлопывание групп при загрузке профиля только по `Id`;
  - добавление группы в конец списка без C#-сортировки;
  - отсутствие `case 21` (боссы) в `LezFight.SelectFoeGroup()`.

## План исправления

- [x] Привести создание группы в `AutoBoiSettingsFragment` к C#-алгоритму вставки.
