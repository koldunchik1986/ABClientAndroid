# Задача: общий fallback URL-резолвер для auto-функций WebView

## Цель
- [x] Добавить общий fallback-слой для авто-навигации в `MainPhp`, чтобы авто-функции не зависели только от одного формата HTML/JS-переменных.

## Проблема
- [x] В ряде кадров сервер отдает урезанный/измененный HTML (например, пустой `fight_ty[9]`), из-за чего точечный парсер не находит ссылку действия.
- [x] Это влияет не только на `AutoSkin`, но и на другие цепочки, где строится redirect из `main.php`.

## План
- [x] Вынести общую нормализацию URL (`http://neverlands.ru`, декод `&amp;`, относительные `main.php`/`/main.php`/`../main.php`).
- [x] Добавить универсальный поиск `main.php?...` по ключевым частям запроса (regex fallback).
- [x] Подключить fallback в `mainPhpFindPerc`, `mainPhpFindInv`, `mainPhpRaz`.
- [x] Унифицировать `buildRedirectHtml(...)`, чтобы все auto-redirect ветки проходили через одну нормализацию.
- [x] Проверить сборку `assembleDebug`.

## Критерии готовности
- [ ] Если основной парсер ссылки не сработал, fallback находит эквивалентный `main.php?...` URL и auto-цепочка не обрывается (проверка на runtime-логах).
- [ ] Редиректы auto-функций работают с `neverlands.ru` (без `www`) и корректными query-параметрами (проверка на runtime-логах).
- [x] Сборка `assembleDebug` успешна.
