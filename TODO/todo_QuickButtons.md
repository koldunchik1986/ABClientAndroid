# План реализации: QuickButtons (быстрые кнопки на основной вкладке)

## Назначение
Добавить на основную вкладку (рядом с webView и чатом) панель из 10 кнопок для быстрого доступа к автофункциям. Кнопки настраиваемые:
- Короткое нажатие: выполнение функции
- Длительное нажатие на "+": выбор функции из списка
- Длительное нажатие на кнопку с функцией: удаление с подтверждением

## Список автофункций (будет расширяться)
1. Автобой (FastAttack)
2. Быстрые действия (QuickActions)
3. Авторыбалка
4. Автоохота
5. Автонападение
6. АвтоНевид
7. Слежение за локацией
8. АвтоОбнаружение
9. АвтоПризыв
10. АвтоЛечение
... (программно обновляемый список)

## План реализации

### Этап 1: Подготовка UI
- [ ] Создать layout `quick_buttons_bar.xml` - горизонтальная полоса с 10 кнопками
- [ ] Добавить панель в `content_main.xml` под status_bar
- [ ] Создать иконку зеленого плюсика `ic_add.xml`

### Этап 2: Модель данных
- [ ] Создать класс `QuickButton` - модель для хранения назначенной функции (id, name, icon, actionType)
- [ ] Создать enum `QuickActionType` - типы действий (AUTO_FIGHT, QUICK_ACTIONS, AUTO_RECALL и т.д.)

### Этап 3: Менеджер кнопок
- [ ] Создать класс `QuickButtonsManager` - управление кнопками
- [ ] Методы: loadButtons(), saveButtons(), assignFunction(), removeFunction()
- [ ] Сохранение в SharedPreferences (список назначенных кнопок)

### Этап 4: Логика кнопок
- [ ] Обработка короткого нажатия - выполнение назначенной функции
- [ ] Обработка длинного нажатия на "+" - показ списка функций
- [ ] Обработка длинного нажатия на кнопку с функцией - диалог удаления

### Этап 5: Интеграция с существующим кодом
- [ ] Интегрировать с FastActionManager
- [ ] Интегрировать с QuickActionsBottomSheet
- [ ] Проверить работу в MainActivity

## Технические детали

### Хранение данных
- SharedPreferences: key="quick_buttons", JSON array [{position, actionType, name}]

### Layout: quick_buttons_bar.xml
```xml
<LinearLayout (горизонтально)>
  <ImageButton x 10 (id: quick_button_0 ... quick_button_9)>
</LinearLayout>
```

### Dialog выбора функции
- AlertDialog со списком ListView
- Список берется из QuickActionType enum
