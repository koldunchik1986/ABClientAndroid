# План реализации: QuickButtons (быстрые кнопки на основной вкладке)

## Назначение
Добавить на основную вкладку (рядом с webView и чатом) панель из 10 кнопок для быстрого доступа к автофункциям. Кнопки настраиваемые:
- Короткое нажатие: выполнение функции
- Длительное нажатие на "+": выбор функции из списка
- Длительное нажатие на кнопку с функцией: удаление с подтверждением

## Список автофункций (будет расширяться)
1. Автобой (FastAttack)
2. Быстрые действия (QuickActions)
3. Авторыбалка
4. Автоохота
5. Автонападение
6. АвтоНевид
7. Слежение за локацией
8. АвтоОбнаружение
9. АвтоПризыв
10. АвтоЛечение
... (программно обновляемый список)

## Технические детали

### Хранение данных
- SharedPreferences: key="quick_buttons", JSON array [{position, actionType, name}]

### Layout: quick_buttons_bar.xml
```xml
<LinearLayout (горизонтально)>
  <ImageButton x 10 (id: quick_button_0 ... quick_button_9)>
</LinearLayout>
```

### Dialog выбора функции
- AlertDialog со списком ListView
- Список берется из QuickActionType enum
