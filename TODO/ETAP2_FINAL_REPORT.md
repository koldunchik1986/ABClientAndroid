## 🏗️ Архитектура ЭТАП 2

### 4 основных метода (650+ строк)
1. **`executeFishingCycleCore()`** - главный оркестратор
   - Загружает озеро из `ContentLakeHtml`
   - Парсит vcode **НЕПОСРЕДСТВЕННО ИЗ озера** (не из act=1!)
   - Вызывает методы парсинга и выбора
   - Контролирует отправку act=1 и act=2

2. **`mainPhpAutoFishPrepareFromLakeAndroid()`** - парсинг озера
   - Извлекает vcode, lakeid, act-параметры
   - Возвращает структурированный `LakeParseResult`

3. **`selectBaitFromLakeHtmlAndroid()`** - выбор приманки
   - Парсит доступные приманки
   - Выбирает оптимальную
   - Возвращает `BaitSelectionResult`

4. **`scheduleNextFishingCycleAttempt()`** - планирование
   - ExponentialBackoff при ошибках
   - Асинхронное планирование через Handler

### 4 DTO класса для структурирования
- `LakeParseResult` - результат парсинга озера
- `BaitSelectionResult` - результат выбора приманки
- `FishBaitInfo` - информация о приманке
- `FishAct1State` - состояние после act=1

### 3 новых вспомогательных метода
- `getMainActivityOrNull()` - получение Activity
- `sendFishAct1RequestWithLake()` - отправка act=1
- `getBaitNameById()` - маппер ID → имя

### 2 новых поля в AppVars
- `FishCurrentLakeid` (int) - ID озера
- `NextFishingAttemptDueAtMs` (long) - время следующей попытки
