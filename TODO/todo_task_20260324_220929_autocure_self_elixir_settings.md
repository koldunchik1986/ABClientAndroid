# Задача: Настройки -> Лечение (приоритет self-лечения эликсиром)

## Контекст
- Нужно добавить раздел `Настройки -> Лечение`.
- Если включен режим лечения эликсиром:
  - сначала пробуем `Эликсир Мгновенного Исцеления` для **своих** выбранных травм;
  - при отсутствии/недоступности эликсира делаем fallback на текущую C#-паритетную ветку с аптечками (`doctorform`, `wca=85`).
- Доп. правила:
  - эликсир не используется для лечения друзей/контактов;
  - боевая травма не лечится эликсиром, только боевой аптечкой.
