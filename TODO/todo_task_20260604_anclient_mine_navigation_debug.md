# Задача: отладка навигации шахты ANClient

## Симптомы

- Фонарь не переодевается, когда ломается: слот руки пустой, но во время навигации по карте шахты новый фонарь не надевается.
- Во время перемещения нельзя отключить навигатор: кнопка навигатора неактивна, хотя пользователь должен иметь возможность остановить маршрут.
- Построенный маршрут на карте шахты не отображается как на карте природы: текущая клетка должна мигать, будущие клетки должны быть красными, между ними нужны стрелки по ходу маршрута.
- Обводка клеток на карте шахты рисуется прямоугольниками вокруг номера, а должна обводить всю картинку клетки квадратом.

## Существующие контуры для проверки

- `ANClient\Mine\AutoMineRuntime.cs` — состояние маршрута, ожидание факела/кирки, логирование `auto_mine_trace`.
- `ANClient\PostFilter\MainPhpAutoMine.cs` — проверка экипировки, редиректы на факел/кирку, wear-ссылки.
- `ANClient\ANForms\FormMainNavigator.cs` / `FormMainMap.cs` — UI навигатора и кнопки остановки.
- `ANClient\PostFilter\MineJs.cs`, `MapJs.cs`, `MapAjax.cs`, `MineAjaxPhp.cs`, `ANClient\map.js` — JS/HTML отрисовка карты и маршрута.

## Диагностика

- Логи найдены в `ANClient\bin\Debug\Logs\Critical\`.
- В `20260604_13_00_auto_mine_trace.log` повторялось `route waits torch check` и `main.php reload requested: source=route_torch_check`.
- В `MainPhpAutoMine.cs` pending route injection выполнялся раньше `ProcessAutoMineTorchCheck()`, поэтому проверка фонаря была недостижима на шахтёрской странице с активным маршрутом.
- Кнопка `Навигатор` раньше чистила только `buttonNavigator.Checked` и `AppVars.AutoMoving`, но шахтёрский pending route жил отдельно в `AutoMineRuntime`.
- Обводка шахтёрского маршрута ставилась на текстовый `<span>` с координатами, поэтому рамка рисовалась вокруг номера, а не всей клетки.

## Реализация

- В `ANClient\PostFilter\MainPhpAutoMine.cs` проверка фонаря/кирки оставлена в существующем контуре и поднята выше pending route injection.
- В `ANClient\Mine\AutoMineRuntime.cs` добавлен `CancelPendingMineRoute(string source)` для штатной отмены pending route без нового параллельного механизма.
- В `ANClient\ANForms\FormMainNavigator.cs` остановка навигатора теперь отменяет pending mine route, чистит `AutoMoving`/`AutoMovingMapPath` и перезагружает `main.php`.
- В `ANClient\Mine\AutoMineRuntime.cs` HTML клетки изменён на full-cell overlay: текущая клетка мигает, будущие клетки выделяются красным, между шагами добавлены стрелки.
- В `ANClient\PostFilter\MineJs.cs` добавлен `rerenderRoute()` и CSS для `anc-mine-current-blink`; rerender вызывается после выбора цели.
