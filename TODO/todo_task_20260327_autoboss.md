# Задача: портирование «Авто-Боссы» (Android, 1:1 по текущей логике проекта)

## Контекст
- Цель: добавить новую авто-функцию `Авто-Боссы` как отдельный модуль `BossAuto.java`, без дублирования уже существующей логики.
- Ограничения:
  - использовать текущие контуры `Auto-Компас`, `FastAction`, `Авто-Бой`, `Авто-Лечение`;
  - не раздувать код дублирующими обработчиками;
  - не менять `ABClient/*`.

## Источники текущей реализации (Android)
- `AutoFunctionsManager` — единая точка флагов авто-функций и запуска/остановки.
- `CompasAuto` — поиск цели по `pinfo` и обход клеток.
- `RoomManager` — актуальный список игроков клетки (`ch.php?lo=1`) и room-update hook.
- `ChatFilter`/`Chat` — поток входящих сообщений и отправка в чат.
- `FastActionManager.fastAttackZas(nick)` — быстрый свиток защиты.

## Сценарий приемки
- [ ] При включенном `Авто-Боссы` и сообщении:
      `Внимание! Случайное событие! Монстр "..." напал на игрока Nickname.`
      извлекается `Nickname` и стартует поиск через `Авто-Компас`.
- [ ] В чат уходит `%<Nickname> Подскажи на какой клетке Босс?`.
- [ ] При ответе `Nickname` с клеткой `XX-XXX` маршрут перестраивается на указанную клетку.
- [ ] После нахождения цели выполняется `FastAction` свиток защиты на `Nickname`.
- [ ] После боя персонаж возвращается на исходную клетку, затем восстанавливаются паузенные авто-функции.
