## Что найдено

- В логе профиль входа шифрованный: `encrypted=true`.
- Для шифрованного профиля в `applySelectedProfile(...)` пароль всегда очищался, `remember` сбрасывался.
- В итоге пароль шифрования не подставлялся после `Logout -> LoginActivity`.

## Что изменено

- В `LoginActivity` добавлен отдельный ключ `SharedPreferences`:
  - `KEY_ENCRYPTED_LOGIN_PASSWORD_PREFIX`.
- Добавлены методы:
  - `getSavedEncryptedLoginPassword(...)`;
  - `persistEncryptedLoginPasswordSnapshot(...)`.
- Добавлен метод:
  - `clearSavedEncryptedLoginPassword(...)` (очистка сохраненного пароля шифрования при удалении профиля).
- В `applySelectedProfile(...)` для `encrypted=true`:
  - теперь подставляется сохраненный пароль шифрования;
  - checkbox `Запомнить пароль` выставляется по факту сохраненного значения.
- В `login()` для `encrypted=true`:
  - при нажатии Войти пароль шифрования сохраняется/очищается по состоянию checkbox.

## Ожидаемая проверка

- Сценарий: вход в шифрованный профиль с включенным `Запомнить пароль` -> выход -> экран логина.
- Ожидание: пароль шифрования подставлен автоматически.
