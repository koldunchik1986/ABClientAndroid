# Анализ `InvEntry.cs` (актуализация)

## 1. Назначение файла в C#

`ABClient/InvEntry.cs` — это ключевая модель элемента инвентаря, которая:
- парсит HTML одного предмета;
- хранит все данные для сравнения/группировки;
- умеет перестраивать HTML записи (`Build`);
- добавляет кнопки массовых действий (`AddBulkSell`, `AddBulkDelete`);
- участвует в 1:1-алгоритме объединения дублей через `CompareTo` + `CompareDolg`.

## 2. Что именно делает C# `InvEntry`

- Конструктор `InvEntry(string html)` извлекает:
  - `Name`, `WearLink`, `DropThing/DropLink/DropPrice`, `PssThing/PssLink/PssPrice`;
  - `img`, `level`, свойства предмета, долговечность (`_dolgOne/_dolgTwo`);
  - срок годности и флаг просрочки (`_expirible`, `_expired`);
  - количество action-кнопок (`_countButton`) как часть ключа сравнения.
- `CompareTo(...)` в C# сложный и чувствительный к множеству полей (не только имя).
- `CompareDolg(...)` сравнивает долговечность через числовые части `x/y`, учитывая полноту.
- `Build()`:
  - для пачки вставляет `(<N> шт.)` в заголовок;
  - для просрочки меняет палитру фона и вставляет маркер `ПРОСРОЧЕНО!`.
- `AddBulkSell()` / `AddBulkDelete()` внедряют дополнительные кнопки в HTML одной записи.

## 5. Матрица паритета (C# -> Android)

| Блок | C# | Android | Статус |
| --- | --- | --- | --- |
| Парсинг одной записи | Полный string-parsing + действия | Базовый Jsoup-парсинг | `[~]` |
| Ключ сравнения | Сложный `CompareTo` | Упрощённый `compareTo` | `[ ]` |
| Сравнение долговечности | `CompareDolg` по `x/y` | Упрощённый string/int compare | `[ ]` |
| Группировка дублей | `MainPhpInv + InvEntry` | `MainPhp.mainPhpInv + model.InvEntry` | `[~]` |
| Bulk Sell/Delete | Полноценные вставки | Частично (базовый сценарий) | `[~]` |
| Просрочка предмета | Подсветка + метка | Отсутствует | `[ ]` |
