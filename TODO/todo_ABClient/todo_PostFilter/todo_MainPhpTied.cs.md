
### 1. План портирования MainPhpTied.cs

Файл `MainPhpTied.cs` содержит вспомогательную функцию для парсинга процента усталости персонажа из HTML-кода страницы.

### 2. Функциональность в C#

- **Назначение:** Извлечь текущую усталость персонажа и обновить соответствующий элемент интерфейса.
- **Логика:**
    1.  Функция получает HTML-код `main.php`.
    2.  Ищет усталость через legacy-маркер `Усталость:</td>...`, более общий HTML-label `Усталость:` и fallback `var hpmp = [...]`.
    3.  Нормализует значение в диапазон `0..100`.
    4.  Вызывает делегат `UpdateTied` на главной форме (`AppVars.MainForm`), чтобы обновить UI и `AppVars.Tied`.

### 3. Решение для портирования на Android

Это вспомогательная функция, которая не модифицирует HTML, а только читает из него данные для обновления UI. Ее логика должна быть воспроизведена в соответствующем парсере на стороне Android.

### 4. План реализации

1.  **Дополнить класс `PlayerStateParser` в Android:**
    - Этот класс будет отвечать за извлечение всей информации о состоянии персонажа со страниц.
2.  **Реализовать метод `parseTied(html)`:**
    - Метод будет искать в HTML-коде и извлекать процент усталости.
    - Возвращать это значение.
3.  **Обновление UI:**
    - Компонент, отвечающий за отображение состояния персонажа, будет вызывать `parseTied(html)` и обновлять соответствующий `TextView`.
