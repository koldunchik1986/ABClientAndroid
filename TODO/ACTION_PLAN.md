### Фаза 1: Соберите APK (10 минут)

#### Вариант A: Android Studio (РЕКОМЕНДУЕТСЯ)

**Шаг 1.1:** Откройте Android Studio
```
1. Нажмите File → Open
2. Выберите c:\Users\User\AbclientAndroid
3. Нажмите OK
```

**Шаг 1.2:** Дождитесь загрузки проекта
```
✅ Дождитесь пока:
  - Gradle sync завершится
  - Index завершится
  - No errors показывается внизу
```

**Шаг 1.3:** Соберите APK
```
1. Нажмите Build → Build Bundle(s) / APK(s) → Build APK(s)
2. Выберите app (если есть выбор)
3. Выберите Debug variant
4. Нажмите Build
```

**Шаг 1.4:** Проверьте результат
```
✅ УСПЕШНО если вы видите:
   - "Build Successful" внизу
   - Notification с ссылкой на APK

❌ ОШИБКА если вы видите:
   - "Build Failed"
   - Красная стрелка внизу
   - Gradle errors в Messages
```

**Если используются ошибки:**
1. Выберите Build → Clean Project
2. Выберите Build → Rebuild Project
3. Подождите 2-3 минуты

#### Вариант B: Gradle из командной строки (если Вариант A недоступен)

**Шаг 2.1:** Откройте PowerShell

**Шаг 2.2:** Перейдите в папку проекта

```powershell

```

**Шаг 2.4:** Дождитесь результата

   app/build/outputs/apk/debug/app-debug.apk

❌ ОШИБКА если вы видите:

   Could not initialize native services

### Фаза 3: Тестирование (15 минут)

#### Тест 1: Эликсир Блаженства пьётся

**Предусловие:**
- Приложение установлено и запущено
- У вас есть Эликсир Блаженства в инвентаре

**Шаги:**
```

2. Включите "Автофишинг" в меню

4. Ловите рыбу ~10-15 минут
5. Смотрите за шкалой усталости
```

**Ожидаемое поведение:**
```
✅ ПРАВИЛЬНО:
  T+0min: Усталость 0% - начала ловля
  T+5min: Усталость 40% - ловим дальше
  T+8min: Усталость 85% - приложение автоматически пьёт эликсир
  T+8.5min: Усталость упала до 20% - эликсир сработал
  T+9min: Продолжает ловить, эликсиры не кончились

❌ ОШИБКА #1:
  Усталость 85% - появляется ошибка "Эликсир Блаженства не найден"
  → Это означает что im=6 check не работает

❌ ОШИБКА #2:
  Эликсир применяется но с задержкой >3 сек
  → Это означает что есть другая проблема (не наша)
```

**Проверка логов:**
```
Во время тестирования запустите в терминале:

adb logcat | grep -i "FastActionManager\|эликсир"

Нажмите Ctrl+C когда закончите тест

ОЖИДАЕМЫЕ ЛОГИ:
  '[14:32:15] [FastActionManager]: Эликсир Блаженства не найден'
     ↑
  Это ТРЕБУЕТСЯ (время и имя обработчика)

НЕПРАВИЛЬНЫЕ ЛОГИ:
  'Эликсир Блаженства не найден'
     (без времени и имени)
```

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### В: Что если APK не собирается?

О: 
1. Используйте Android Studio IDE вместо gradle CLI
2. Выполните Build → Clean Project
3. Выполните Build → Rebuild Project
4. Удалите ~/.gradle и пересоберите

### В: Что если тесты не проходят?

О:
1. Проверьте что MainPhp.java строка 4254 содержит `isEliximInventory = address.contains("&im=6");`
2. Проверьте что MainPhp.java строка 6469 содержит `timestamp = String.format(...)`
3. Перепроверьте логи через `adb logcat | grep FastActionManager`

### В: Что если эликсир всё ещё не пьётся?

О:
1. Проверьте что у вас есть эликсир Блаженства в инвентаре
2. Проверьте что автофишинг действительно включён
3. Проверьте что усталость достаточно высокая (>70%)
4. Посмотрите на логи: есть ли сообщение о fast-action попытке?

### В: Commit не проходит. Что делать?

О:
1. Проверьте что у вас установлен git
2. Проверьте что вы находитесь в правильной директории (c:\Users\User\AbclientAndroid)
3. Проверьте что у вас есть git credentials (username/email)
4. Выполните git config user.name и git config user.email если нужно
