# План портирования FormMainTabs.cs

## Назначение файла

Файл `FormMainTabs.cs` содержит основную логику системы вкладок WinForms-приложения ABClient. Реализует управление вкладками через `TabControl`, включая создание, переключение, закрытие и восстановление состояния вкладок.

## Функциональность в C#

### 1. Типы вкладок (TabType)
- **Game** (0) - основная игра (main.php)
- **Forum** (1) - форум `forum.neverlands.ru`
- **PInfo** (2) - информация об игроке `neverlands.ru/pinfo.cgi?Nickname`
- **PName** (3) - поиск по имени
- **PBots** (4) - боты
- **Log** (5) - бой (лог)
- **Room** (6) - комната
- **TodayChat** (7) - сегодняшний чат
- **Other** (100) - прочие ссылки
- **Notepad** (200) - блокнот

### 2. UI-компоненты вкладки
Каждая вспомогательная вкладка содержит:
- **ToolStrip** с кнопками (набор зависит от типа вкладки):
  - `Назад` - возврат на предыдущую страницу
  - `Обновить` / `Перечитать` - обновление страницы
  - `Закрыть` - закрытие вкладки
  - `Компас` - поиск положения на природе (для PInfo/PName)
  - `Приват` - открыть приватный чат с игроком
  - `В контакты` - добавить в контакты
  - `Весь клан` - добавить весь клан в контакты
  - `Снимок` - сделать скриншот вкладки
  - `Копировать адрес` - копирует URL в буфер обмена
- **Label** с адресом страницы

### 3. Ключевые методы

#### InitGameTab()
Инициализация основной вкладки игры. Устанавливает никнейм игрока как заголовок вкладки.

#### BeforeNewWindow(string tourl)
Обработчик открытия нового окна. Анализирует URL и создаёт соответствующую вкладку:
- Если URL форума → `TabType.Forum`
- Если URL pinfo → `TabType.PInfo`
- Если URL комнаты → `TabType.Room`
- И т.д.

#### CreateNewTab(TabType tt, string tourl, bool delayed)
Создание новой вкладки. Основной метод:
1. Проверяет, не открыта ли уже такая вкладка
2. Создаёт WebBrowser или TextBox (для блокнота)
3. Создаёт ToolStrip с кнопками
4. Добавляет вкладку в TabControl
5. Сохраняет состояние вкладок

#### TabChanged()
Обработка переключения между вкладками. Для отложенных (delayed) вкладок - загружает URL при первом показе.

#### TabClose()
Закрытие вкладки. Удаляет TabPage из TabControl и освобождает ресурсы.

#### SaveTabs() / LoadTabs()
Сохранение и загрузка списка открытых вкладок в профиль пользователя.

## Решение для портирования на Android

### Компоненты Android:
1. **TabLayout** (Material Design) - горизонтальные вкладки под Toolbar
2. **FrameLayout** - контейнер для содержимого вкладок
3. **WebView** - для каждой вспомогательной вкладки
4. **TabManager** - класс для управления вкладками (уже существует в Android-проекте)

### Типы вкладок в Android:
| C# TabType | Android |
|------------|---------|
| Game | tab_main_content (main.php + чат) |
| Forum | secondary tab |
| PInfo | secondary tab |
| PName | secondary tab |
| PBots | secondary tab |
| Log | secondary tab |
| Room | secondary tab |
| TodayChat | не реализовано |
| Notepad | не реализовано |
| Other | secondary tab |

### Реализация кнопок:
- **Назад/Обновить** - встроены в WebView
- **Закрыть** - long-press на Tab или кнопка в toolbar
- **Компас/Приват/Контакты** - пока не реализованы
