# Debug Log 20260227_203500

- **Обоснование:** Пользователь сообщает, что при включенном автобое висит надпись «Завершение боя», переход не происходит.

- **Действие:**

- **Обоснование:** Абсолютный URL нужен, чтобы WebView/interceptor действительно загрузили `get_id=61&act=7`; ручной режим не должен перехватываться.
- **Результат:** Код обновлён, логирование сохранено.
