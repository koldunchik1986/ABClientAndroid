## БЫСТРЫЕ ОТВЕТЫ

### ❓ Почему хисит vcode?
```
ПК: каждый цикл загружает озеро → парсит vcode ИЗ НЕГО
Android: приложение УЧИТЫВАЕТ vcode ИЗ act=1 response
Результат: vcode может быть для ДРУГОГО действия или УСТАРЕВШИЙ
```

### ❓ Почему не грузит озеро?
```
ПК: NeverTimer истёк → GET main.php?get_id=55 → parseParams → действие
Android: kickFishCycleAttempt() → act=1 зонд → scheduleNoCaptchaAct2Fallback()
Результат: основная загрузка озера ОТСУТСТВУЕТ
```

### ❓ Почему не проверяет остаток?
```
ПК: На озере ищет HTML "<b>123</b>" → проверяет > 4
Android: selectAllowedBait() просто выбирает первую
Результат: может попытаться использовать НЕСУЩЕСТВУЮЩУЮ приманку
```

### ❓ Где основной цикл?
```
ПК: FormMainTick() → NeverTimer проверка → загрузка озера
Android: ❌ ОТСУТСТВУЕТ
Результат: нет единой точки входа в цикл
```

## РЕШЕНИЕ (ОДНА СТРОКА)

**Нужно**: Создать `executeFishingCycleCore()` который:
1. Загружает main.php?get_id=55
2. Вызывает mainPhpAutoFishPrepareAndroid()
3. Парсит vcode/приманку/капчу ИЗ ОЗЕРА
4. Отправляет действие с СВЕЖИМ vcode

## ЖЕ ВОПРОСЫ НА ОЧЕРЕДИ

1. ❓ Как загрузить озеро синхронно? 
   → Нужен кэш озера или синхронный HTTP

2. ❓ Где вызывать executeFishingCycleCore()?
   → Из kickFishCycleAttempt() или из scheduleNextCycle()

3. ❓ Что делать с processFishAct1()?
   → Оставить как ВСПОМОГАТЕЛЬНЫЙ (только для синхронизации)

4. ❓ Совместимость с captcha?
   → Будет работать лучше (свежий vcode для капчи)
