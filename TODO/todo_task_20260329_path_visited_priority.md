# Задача: приоритет `visited` в выборе маршрута

## Цель
- При равных маршрутах выбирать путь через более «старую» ближайшую клетку.
- Если у ближайшей клетки нет `visited`, считать её самой старой (максимальный приоритет).
- Убрать случайность выбора равных путей, сделать детерминированный выбор.

## Чеклист реализации
- [x] Добавлен tie-break по `visited` ближайшей соседней клетки в `MapPathNode.compareTo(...)`.
- [x] Политика отсутствующего `visited`: считается самой старой меткой.
- [x] Убран случайный выбор из `MapPath` (`Random`) при равных кандидатов.
- [x] Добавлен детерминированный выбор лучшего пути (фиксированный порядок при полном равенстве).

## Проверки
- [ ] Проверить в runtime, что Авто-Компас при равных путях стабильно выбирает клетку со старым/пустым `visited`.
- [ ] Проверить в runtime, что Авто-Клад не деградировал по скорости/стабильности переходов.
- [ ] Проверить в логах отсутствие random-перекидывания между равными маршрутами.
