## Описание системы вкладок в C# версии

Система вкладок в C# реализована через:
- **TabControl** (`tabControlLeft`) - стандартный WinForms TabControl
- **TabPage** - каждая вкладка представляет собой TabPage с WebBrowser внутри
- **ToolStrip** - панель инструментов внутри каждой вкладки с кнопками

### Типы вкладок (TabType):
- `Game` (0) - основная игра
- `Forum` (1) - форум
- `PInfo` (2) - информация об игроке
- `PName` (3) - поиск игрока по имени
- `PBots` (4) - боты
- `Log` (5) - бой
- `Room` (6) - комната
- `TodayChat` (7) - сегодняшний чат
- `Other` (100) - другие ссылки
- `Notepad` (200) - блокнот

### Функции создания/управления вкладками:
- `CreateNewTab(TabType, url, delayed)` - создание новой вкладки
- `BeforeNewWindow(url)` - обработка открытия нового окна
- `TabChanged()` - переключение между вкладками
- `TabClose()` - закрытие вкладки
- `SaveTabs()` / `LoadTabs()` - сохранение/загрузка состояния вкладок
