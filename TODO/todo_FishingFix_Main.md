# Основной план: Исправление ошибки "неверный код защиты" при авто-рыбалке

**Проблема:** При авто-рыбалке 2-я и последующие ловли получают ошибку `"неверный код защиты"`.

**Корневая причина:** Android версия парсит vcode из **act=1 response**, который имеет TTL 5 минут. ПК-версия парсит vcode из **озера HTML**, который обновляется каждый цикл.

## Технические детали ЭТАП 2

### Основная идея
Правильный цикл авто-рыбалки:
1. **Загрузить озеро** → ContentLakeHtml заполнен
2. **Парсить vcode ИЗ озера** (не из act=1!)
3. **Отправить act=1** → получить информацию о состоянии
4. **Отправить act=2** → с СВЕЖИМ vcode из озера
5. **Избегать повторной загрузки озера** → переиспользовать кэш 5 минут

### Алгоритм executeFishingCycleCore()
```
1. Проверить что ContentLakeHtml заполнен (если нет → bootstrap)
2. Парсить озеро → LakeParseResult (vcode, lakeid, act_list)
3. Выбрать приманку → BaitSelectionResult (best bait with max stock)
4. Сохранить vcode→AppVars.FishCurrentVcode
5. Отправить act=1 (через async callback)
6. На回应 act=1 → отправить act=2 с сохраненным vcode
7. Обработать результат act=2
8. Спланировать next cycle через scheduleNextFishingCycleAttempt()
```

### ExponentialBackoff стратегия
- Успех: 5 минут до следующей попытки
- Ошибка 1-я: 30 секунд
- Ошибка 2-я: 60 секунд
- Ошибка 3-я: 2 минуты
- Captcha требуется: 10 минут
- Критическая ошибка: 15 минут
