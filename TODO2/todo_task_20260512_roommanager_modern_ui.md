## Найденный существующий контур

- [x] `RoomManager.process(...)` обрабатывает `ch.php?lo=1`, парсит `ChatListU`, синхронизирует локацию и запускает авто-логику.
- [x] UI списка игроков строится в `RoomManager.injectPlayerListHtmlIntoChatPhp(...)`, где Java-side HTML вставляется вместо `chatlist_build(...)`.
