# Авто-Лесоруб для app2/ANClient

Дата: 2026-05-01

## Назначение

Реализовать `Авто-Лесоруб` в `app2/ANClient` как специализированный режим существующего контура `Авто-Травник`: тот же маршрут по карте, тот же `alchemy_ajax.php`, та же обработка таймеров, капчи, повторного действия на клетке и очистки инвентаря, но с деревьями и топорами.

## Источники

- `ogl_srez_oreshnik.har` — эталонный трафик `Оглядеться`/`Спилить` для дерева `Орешник`.
- `wiki/Таблица Лесоруба — Викиневер.html` — список деревьев и данные для выбора ресурсов.
- `app2/src/main/java/ru/neverlands/anclient/manager/AutoCutManager.java` — текущий runtime-контур авто-травника.
- `app2/src/main/java/ru/neverlands/anclient/postfilter/AlchemyAjaxPhp.java` — обработка `alchemy_ajax.php` и результатов среза/спила.
- `app2/src/main/java/ru/neverlands/anclient/postfilter/AutoCutHandler.java` — подготовка инструмента и очистка после quick action.
- `app2/src/main/java/ru/neverlands/anclient/bridge/WebAppInterface.java` — JS bridge для запуска/диагностики `map.js`.
- `app2/src/main/assets/js/map.js` — существующий JS-контур `Ogl(...)`, `HerbsList(...)`, `TraceCut(...)`.
- `app2/src/main/java/ru/neverlands/anclient/model/QuickActionType.java` — список быстрых автофункций.
- `app2/src/main/java/ru/neverlands/anclient/license/LicenseFeature.java` — лицензирование non-public фич.

## Анализ HAR

- `Оглядеться`: `gameplay/ajax/alchemy_ajax.php?act=1&vcode=...&r=...`.
- Ответ `act=1` содержит массив найденных ресурсов: травы и деревья могут приходить в одном списке.
- Пример `Орешник`: `[261,"Орешник",30,30,209397049,10,2,2,1,"522496d14d51781a8a2cc142812a245e",9,1]`.
- `r_type=9` в примере отличает дерево от травяного ресурса.
- `Спилить`: `act=3&res_id=261&r_x=993&r_y=999&r_time=30&r_type=9&uid=209397049&curs=10&mass=2&p=2&l_time=30&vcode=...&code=52022`.
- Успех: `RESO@["Всё прошло успешно."]@[]...@[0,[1,600]]@[]`.

## Инструменты лесоруба

Подготовка инструмента должна использовать инвентарный фильтр `main.php?wca=2`, а не текущий травяной `wca=4`.

- `Мачете`
- `Столярный топорик`
- `Плотницкий топор`
- `Топор подмастерья`
- `Топор дровосека`
- `Секира лесоруба`
- `Секира Мастера-лесоруба`

## Деревья

Список деревьев нужно брать из `wiki/Таблица Лесоруба — Викиневер.html`. На этапе реализации требуется извлечь реальные названия и использовать их в Android-фильтре ресурсов вместо травяного списка.

## Найденный существующий контур

- Запуск автофункции идет через `QuickActionType.AUTO_CUT`, `AutoFunctionsManager` и `AutoCutManager`.
- Карта/JS вызывает `window.external` методы в `WebAppInterface`, отдельный HTTP-контур не нужен.
- `AlchemyAjaxPhp` уже парсит `act=1` и `act=3`, поэтому для лесоруба нужно расширить resource-mode/фильтрацию, а не писать новый обработчик запросов.
- `AutoCutHandler` уже отвечает за подготовку инструмента и очистку `Бесполезный хлам`; требуется параметризовать инструментальный фильтр и названия инструмента.
- Логирование уже идет через `AppLog` и `AutoCutManager.TRACE_CHAIN`; новый режим должен использовать тот же файловый trace chain или отдельный chain без прямого `android.util.Log`.

## Архитектурное решение

- Не создавать новый scheduler, route manager, HTTP client или captcha solver.
- Расширить существующий AutoCut-контур режимом ресурса: `HERB` и `TREE`.
- Для UI и лицензии добавить отдельную автофункцию `Авто-Лесоруб` с ключом `auto_lumberjack`.
- Для runtime использовать общий manager/handler там, где алгоритм совпадает, с параметрами режима: название функции, список ресурсов, `r_type`, icon, инструментальный фильтр, имена инструментов.
- Сохранить поведение `Авто-Травник` без изменения результата: действующие флаги, таймеры, retry и checked-set должны продолжать работать.

## Лицензирование

- `auto_lumberjack` должен быть non-public как `auto_cut`.
- В UI функция должна отображаться только при наличии лицензии.
- Нельзя добавлять public fallback, который делает функцию доступной всем пользователям.

## Риски и проверки

- Если `act=1` возвращает травы и деревья вместе, фильтр должен выбирать только ресурсы текущего режима.
- Если `r_type=9` не единственный признак дерева, список названий из wiki должен быть дополнительной защитой.
- Если обе автофункции включены одновременно, нужно избежать конкуренции за карту и `alchemy_ajax.php`.
- Если нет подходящего топора, функция должна остановиться/пропустить цикл с понятным логом, а не пытаться использовать серп.
- При `SessionManager.getValidVCodeForAction(...) == null` запрос должен быть пропущен с логом и fallback на следующий цикл/обновление контекста.
- После quick action `FastNeed` должен очищаться existing cleanup-контуром.
