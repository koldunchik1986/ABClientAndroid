# Портирование APIForms: ForpostBuildings.cs и CityHall.cs

## Назначение исходных файлов

`CityHall.cs` и `ForpostBuildings.cs` из `IBClient/APIForms` реализуют справочные WinForms-окна ПК-клиента iBClient/ABClient. Они не выполняют игровых действий, а получают текстовые справочники Neverlands и показывают их пользователю в отдельных формах.

## CityHall.cs

### Функциональность в C#

- Форма содержит две кнопки выбора города и текстовые области/картинку.
- Нажатие первой кнопки вызывает `kqVepB5onI(1)`, второй - `kqVepB5onI(2)`.
- Данные загружаются через `vIVQa9DRcr0ECSqonbX.iD9DX9WYdE(arg0)`.
- URL источника: `http://service.neverlands.ru/info/cityhall_{0}.txt`.
- Ответ делится по `\n`.
- Первая строка содержит общую информацию города, поля разделены `|`.
- Вторая строка содержит список строений, из неё удаляется служебный маркер и затем строка делится по `@`.
- Каждый элемент строения делится по `,`; пустые элементы пропускаются.
- Третья строка используется для картинки/герба и подписи через вложенный класс `rULb4ptLvaedWr7gYiRa`.

### План Android

- Создать отдельный `ForpostInfoActivity` для бокового меню.
- Внутри Activity сделать вкладку `Ратуша`.
- Загружать `cityhall_1.txt` и `cityhall_2.txt` через существующий `NetworkClient`/OkHttp.
- Парсить общий блок и список зданий в Java-модели без прямого использования WebView.
- В UI показать переключатели городов, статус загрузки, общий блок и таблицу зданий.

## ForpostBuildings.cs

### Функциональность в C#

- Форма содержит 6 кнопок категорий и группу из 14 ресурсных позиций.
- Конструктор/инициализация получает общий справочник через `vIVQa9DRcr0ECSqonbX.XGPDP9ui91()`.
- Кнопки вызывают `iL2svZr3kc(sLTsuyeKg8[index])` для выбранной категории.
- `iL2svZr3kc` берёт третье поле строки категории (`split(',')[2]`), делит его по `@`, строит 14 объектов `FOrIy2saIUiAGNZNRlj`, выводит картинку/название/стоимость и суммирует два числовых поля.
- В UI явно присутствуют категории `Ресурсы`, `Станция дирижаблей`, `Рынок`; остальные названия в декомпилированном коде обфусцированы, поэтому Android должен парсить название категории из данных при наличии, а не жёстко зависеть от WinForms-полей.

### План Android

- В той же Activity сделать вкладку `Форпост`.
- Поддержать сетевую загрузку справочника форпоста из набора вероятных service URL с fallback-отображением диагностического сообщения, если сервер недоступен.
- Реализовать гибкий парсер категорий: строки по `\n`, поля категории по `,`, позиции ресурсов по `@`, поля ресурса по `|`, `;`, `~` или `,`.
- Отображать категории кнопками/чипами; при выборе показывать 14 карточек ресурса и итоговые значения.
