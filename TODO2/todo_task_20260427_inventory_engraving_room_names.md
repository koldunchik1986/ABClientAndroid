# Задача: имена комнат в гравировках инвентаря

## Цель

- [x] Найти существующий контур обработки HTML инвентаря в `app2`.
- [x] Найти существующий источник названий клеток карты (`ExtMap`/`RoomManager`).
- [x] Добавить замену координатной гравировки вида `Гравировка: 1033,1000` на `placename` из `ch.php?lo=1&r=m_1033_1000`.
- [x] Проверить сборку `:app2:assembleDebug`.
- [x] Проверить UTF-8 без BOM и отсутствие mojibake в изменённых файлах.

## Решение

Новый helper `InventoryEngravingResolver` подключён в существующий `InventoryParser.mainPhpInv(...)`, без параллельного контура обработки инвентаря.

Алгоритм:

- сначала используется уже загруженное имя клетки из `ExtMap`;
- если имени нет, выполняется точечный запрос `ch.php?lo=1&r=m_x_y` через `NeverApi` с браузерным User-Agent и cookies текущей WebView-сессии;
- из ответа берётся `<font class=placename><b>...</b>`;
- при включённой настройке `MapRebuildFromPinfo` найденное имя дополнительно синхронизируется в карту через `ExtMap.syncCellLabelFromCoordinates(...)`.
