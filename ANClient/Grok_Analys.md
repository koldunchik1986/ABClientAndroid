# Анализ и предложения по улучшению ANClient C# ПК версии\n\n## Обзор кодовой базы\n\n- **Архитектура**: WinForms приложение с WebBrowser (IE-based) для эмуляции браузера игры (Neverland-подобная MMORPG).\n- **Ключевые компоненты**:\n  - `ANForms/FormMain*.cs`: Partial классы основной формы (~30 файлов, дублированный event-handling).\n  - `ANProxy`: HTTP proxy для перехвата/модификации трафика.\n  - `PostFilter/*.cs`: ~40 фильтров для post-processing JS/PHP ответов сервера.\n  - Managers: RoomManager, ContactsManager, ScriptManager.\n  - XML configs: ancells.xml, anthings.xml и т.д.\n- **Размер**: 200+ .cs файлов, фокус на парсинге DOM/JS, автоматизации (bots, nav, fight).\n\n## Выявленные проблемы\n\n### 1. Масштабное дублирование кода (основная проблема)\n- **FormMain partials**: Каждый файл (~100-500 строк) содержит:\n  ```csharp\n  // Пример из FormMain.cs, FormMainChat.cs, FormMainMap.cs\n  private void wb_DocumentCompleted(...) {\n      try {\n          Log.Write(...);\n          string js = \"eval('...')\";\n          wb.Document.InvokeScript(\"eval\", new object[] { js });\n          // Parse DOM via JS return\n      } catch { }\n  }\n  private void timer_Tick(...) {\n      // Similar JS query + parse + action\n  }\n  ```\n  Дубли: Log.Write, JS injection, regex parsing, UI Invoke.\n- **PostFilter**: Каждый *.cs парсит уникальный endpoint похожим способом (string replace, regex на HTML/JS).\n  Пример MainPhpFight.cs: 150+ строк на один бой.\n- **Timers**: 10+ timers с похожей логикой polling DOM.\n\n### 2. Производительность и стабильность\n- Синхронный JS eval блокирует UI.\n- Regex-heavy parsing на UI thread.\n- Нет async/await, Tasks.\n- WebBrowser (IE11 max) устарел, уязвим, медленный JS.\n- Memory leaks: undisposed timers, WebBrowser caches.\n- Exception swallowing: empty catch{} везде.\n- Нет DI, globals в AppVars.cs.\n\n### 3. Maintainability\n- Магическая константы в коде.\n- XML configs хрупкие.\n- Нет тестов.\n- Hardcoded paths/JS snippets.\n\n## Предложения по исправлениям\n\n### 1. **Рефакторинг дублирования: Modular Bot Architecture**\nПерейти от partial FormMain к composable modules.\n\n**Интерфейс модуля:**\n```csharp\npublic interface IBotModule : IDisposable {\n    string Name { get; }\n    void OnDocumentCompleted(HtmlDocument doc);\n    void OnTimerTick(DateTime now);\n    Task<bool> HandleNavigation(Uri url);\n}\n```\n\n**Базовый модуль:**\n```csharp\npublic abstract class BaseBotModule : IBotModule {\n    protected readonly ILogger<IBotModule> _log;\n    protected readonly IJsExecutor _js;\n    protected readonly IConfig _config;\n\n    protected string SafeJsEval(string script) =>\n        _js.Eval(script)?.ToString() ?? \"\";\n\n    protected void LogInfo(string msg) => _log.LogInfo(msg);\n    // Common parse methods\n}\n```\n\n**Примеры модулей:**\n```csharp\n// ChatModule.cs\npublic class ChatModule : BaseBotModule {\n    public override void OnDocumentCompleted(HtmlDocument doc) {\n        var msgs = SafeJsEval(\"document.querySelectorAll('.chat-msg')\");\n        // Parse/process\n    }\n}\n\n// FightModule.cs (ex MainPhpFight)\npublic class FightModule : BaseBotModule {\n    // Reuse parse logic\n}\n```\n\n**В FormMain:**\n```csharp\nprivate readonly List<IBotModule> _modules = new();\nprivate readonly System.Timers.Timer _mainTimer;\n\npublic FormMain() {\n    _modules.Add(new ChatModule(services));\n    _modules.Add(new MapModule(services));\n    // ...\n\n    wb.DocumentCompleted += (s,e) => {\n        Invoke(() => {\n            foreach(var m in _modules) m.OnDocumentCompleted(wb.Document);\n        });\n    };\n\n    _mainTimer = new(100); // One central timer\n    _mainTimer.Elapsed += (s,e) => {\n        foreach(var m in _modules) m.OnTimerTick(e);\n    };\n    _mainTimer.Start();\n}\n```\n\n### 2. **Централизованный PostFilter: Rule-Based Engine**\n```csharp\npublic class FilterEngine {\n    private readonly Dictionary<string, Func<HttpResponse, Task<HttpResponse>>> _rules = new();\n\n    public void Register(string pathPattern, Func<HttpResponse, Task<HttpResponse>> processor) {\n        _rules[pathPattern] = processor;\n    }\n\n    public async Task<HttpResponse> Process(HttpResponse resp) {\n        var rule = _rules.FirstOrDefault(r => resp.Url.Path.Contains(r.Key));\n        return await rule.Value?.Invoke(resp) ?? resp;\n    }\n}\n\n// Usage in Proxy\nproxy.RegisterFilter(\"/main.php?fight\", FightProcessor.ProcessAsync);\n```\nMerge 40 filters в 10-15 универсальных.\n\n### 3. **Modern Stack Upgrades**\n- **Browser**: NuGet CefSharp.WinForms (Chromium).\n  ```xml\n  <PackageReference Include=\"CefSharp.WinForms\" Version=\"119.4.10\" />\n  ```\n  Replace WebBrowser => ChromiumWebBrowser.\n- **HTTP**: HttpClientFactory.\n- **DI**: Microsoft.Extensions.Hosting, IServiceProvider.\n- **Parsing**: HtmlAgilityPack + AngleSharp.\n  ```csharp\nvar doc = new HtmlDocument();\ndoc.LoadHtml(html);\nvar nodes = doc.DocumentNode.SelectNodes(\"//div[@class='fight']\");\n  ```\n- **Config**: appsettings.json + IOptions<T>.\n- **Logging**: Serilog.Sinks.File + Seq.\n- **Async**: Task.Run для parse, SemaphoreSlim для concurrency.\n\n### 4. **Конкретные фиксы багов**\n- **UI Blocks**: \n  ```csharp\n  private async void timer_Tick() {\n      await Task.Run(() => ParseHeavy());\n      UpdateUI();\n  }\n  ```\n- **Dispose**:\n  ```csharp\n  protected override void Dispose(bool disposing) {\n      _mainTimer?.Stop();\n      _modules.ForEach(m => m.Dispose());\n      base.Dispose(disposing);\n  }\n  ```\n- **Exceptions**: GlobalHandler + Polly retries.\n\n### 5. **План внедрения (Todos)**\n1.
