# app3gui — GUI-менеджер лицензий ANClient

Windows Forms-оболочка над Java-инструментом `app3` (`ru.neverlands.anclient.license.AnLicenseTool`).
Заменяет `app3_menu.bat` / `app3_menu.ps1` удобным графическим интерфейсом.

---

## Принцип работы (важно)

**Вся криптография и формат лицензий остаются в Java-инструменте `app3`.**
GUI ничего не подписывает, не шифрует и не разбирает самостоятельно — он только:

1. собирает параметры в удобной форме;
2. запускает `AnLicenseTool` с нужными аргументами;
3. красиво показывает вывод.

Это сделано намеренно. Порт логики на C# означал бы **вторую реализацию** RSA-подписей,
AES-GCM, формата ANREQ1/ANREG2, расчёта цепочки `chainSeq`/`chainTip`, хэшей ников и
noise-добивки до 5 MiB. Любое расхождение хотя бы в одном байте сделало бы **все ранее
выданные `profile.reg` недействительными**. Единый источник истины безопаснее.

## Требования

| Компонент | Назначение |
| --- | --- |
| .NET SDK 10 (или Runtime 10 + Desktop) | запуск самого GUI |
| JDK 17 (переменная `JAVA_HOME` либо `java` в PATH) | запуск инструмента лицензий |
| Собранный `app3` | `app3/build/libs/app3.jar` (кнопка «Собрать app3» сделает это) |

---

## Сборка и запуск

```powershell
dotnet build app3gui\AnLicenseGui.csproj -c Release
.\app3gui\bin\Release\net10.0-windows\AnLicenseGui.exe
```

Для отладочной сборки:

```powershell
dotnet run --project app3gui\AnLicenseGui.csproj
```

## Возможности (паритет с app3_menu)

| Операция в GUI | Команда инструмента |
| --- | --- |
| Проверить файл лицензии | `inspect-license <profile.reg>` |
| Прочитать заявку от устройства | `decode-request <request.txt> [отчёт]` |
| Выдать / обновить доступ | `issue <request.txt> <profile.reg> <срок> <доступ ника> <общий доступ>` |
| Подготовить ключи администратора | `init-keys` |
| Перевыпустить ключи | `init-keys --force` |
| Собрать app3 | `gradlew --no-daemon :app3:build` |

Пункты меню 5-8 из `app3_menu` (полный доступ / базовый / только общий / ручной выбор)
объединены в одну форму «Выдать / обновить доступ»: срок, доступ ника и общий доступ
выбираются из списков **или вводятся вручную** (например CSV `auto_fight,auto_fish,clans`).

## Особенности реализации

### Рабочий каталог

`AnLicenseTool.resolveRoot()` ищет `settings.gradle` в текущем каталоге или в родительском,
а относительные пути аргументов резолвятся от рабочего каталога процесса.

Поэтому GUI **всегда запускает Java с рабочим каталогом = корень проекта**. Благодаря этому
пути работают ровно так, как описано в `app3/instruction.md` (например `app3/request/profile.reg`).

> Примечание: у Gradle-таски `:app3:run` рабочий каталог — `app3/`, поэтому там тот же путь
> нужно писать как `request/profile.reg`. GUI этой особенности лишён.

### Кодировка

Java запускается с `-Dfile.encoding=UTF-8`, `-Dsun.stdout.encoding=UTF-8`,
`-Dsun.stderr.encoding=UTF-8`, а вывод читается как UTF-8. Без этого русский текст
(ники, названия функций) приходит в виде кракозябр — это ровно та проблема, которая видна
при запуске инструмента через обычную консоль Windows.

### Безопасность

* `init-keys --force` требует ручного ввода слова `FORCE` в отдельном диалоге с
  предупреждением: операция делает недействительными **все** выданные лицензии.
* Операция «Проверить файл лицензии» полностью безопасна — только чтение.

### Интерфейс

* Асинхронный запуск: интерфейс не зависает, есть кнопка «Отмена».
* Журнал с подсветкой: команды — синим, успех — зелёным, предупреждения — жёлтым, ошибки — красным.
* Панель «Окружение» показывает найденный корень проекта, наличие сборки app3, путь к Java,
  наличие ключей администратора и публичных ключей в app2.
* Кнопка «Выбрать корень проекта…» — на случай, если автопоиск не сработал.

## Структура

| Файл | Назначение |
| --- | --- |
| `Program.cs` | точка входа |
| `ProjectPaths.cs` | поиск корня проекта, jar, java, служебных папок |
| `ToolRunner.cs` | асинхронный запуск Java/Gradle, чтение вывода в UTF-8, подсветка строк |
| `MainForm.cs` | основное окно: выбор операции, параметры, журнал |
| `ForceConfirmDialog.cs` | подтверждение опасного перевыпуска ключей |

## Что НЕ нужно делать

* Не коммитить `app3gui/bin` и `app3gui/obj` (см. `.gitignore`).
* Не переносить криптологику из `AnLicenseTool.java` в C# — см. раздел «Принцип работы».
* Не запускать перевыпуск ключей без реальной необходимости.
